# SonarQube et SonarCloud 

Sonar est une plateforme d'analyse statique de code qui mesure et améliore la qualité  et la sécurité du code source en continu.

## Intégration sur IDE

Sur IntelliJ (ou autre JetBrains):

- Télécharger le plugin `SonarQube for IDE`
- Dans les settings:
  
  - tools > SonarQube for IDE >  Project
  - Dans `Connections to SonarQube` : cliquer sur le `+`  
  - Indiquer un nom
  - S'assurer que le `SonarQube cloud` est coché
  - Appuyer sur `next`
  - Cliquer sur `generate token`
  - Autoriser la connexion
  - Cliquer sur `next`
  - Sélectionner `Enervision`
